# สเปกดีไซน์ UI หน้าหลัก (Home Screen) — แอป SportBuddy

**บริบท:** แอปหาเพื่อนเล่นกีฬาสำหรับนักศึกษามหาวิทยาลัย เป้าหมายดีไซน์คือความรู้สึก "มืออาชีพ กระตือรือร้น สะอาดตา" พร้อมขึ้น Play Store จริง

---

## 1. แนวคิดการออกแบบโดยรวม

โครงสร้างสีแบ่งหน้าที่ชัดเจนสองสี:

- **สีเขียวมรกต-จังเกิล (Emerald Jungle Green)** = สีแบรนด์หลัก ใช้กับ Header, ไอคอน, ตัวอักษรสำคัญ, องค์ประกอบนำทาง — สื่อถึงความสด ธรรมชาติ พลังงาน และความน่าเชื่อถือ
- **สีเหลืองทอง (Golden Yellow)** = สงวนไว้เฉพาะปุ่ม CTA ที่ต้องการให้ผู้ใช้ "ลงมือทำ" เท่านั้น (เข้าร่วมแมตช์, เชื่อมต่อ) เพื่อให้ปุ่มเหล่านี้โดดเด่นแยกจากองค์ประกอบอื่นทันทีที่กวาดตา
- **พื้นหลังขาว/เทาอ่อน** เป็นพื้นที่ส่วนใหญ่ของหน้าจอ เพื่อให้การ์ดและเนื้อหาดูโปร่ง ไม่อึดอัด ตัดกับสีเขียว/เหลืองได้ชัดเจน

หลักการสำคัญ: **สีเขียว = แบรนด์/นำทาง, สีเหลือง = การกระทำ** ไม่ใช้ปนกันแบบสุ่ม เพื่อให้ผู้ใช้เรียนรู้ pattern ได้เร็วว่าปุ่มสีเหลืองคือปุ่มที่ต้องกดเสมอ

## 3. ระบบตัวอักษร (Typography)

แนะนำฟอนต์ตระกูล **Poppins** (หัวข้อ) คู่กับ **Inter หรือฟอนต์ระบบ** (เนื้อหา) — Poppins ให้ความรู้สึกทันสมัย โค้งมน เป็นมิตรกับกลุ่มนักศึกษา ส่วน Inter อ่านง่ายในขนาดเล็ก

| ระดับ | ฟอนต์/น้ำหนัก | ขนาด | สี | ตัวอย่างการใช้งาน |
|---|---|---|---|---|
| Display (ทักทาย) | Poppins Bold 800 | 24–26px | ขาว (บน Header เขียว) | "ยินดีต้อนรับกลับมา, ปอนด์ 👋" |
| Section Title | Poppins Bold 700 | 18–20px | `green.600` | "แมตช์ที่มีให้เข้าร่วม" |
| Card Title | Poppins SemiBold 600 | 16px | `gray.900` | "หาผู้เล่นบาสเกตบอล 3x3" |
| Body | Inter Regular 400 | 14px | `gray.900` | คำอธิบายแมตช์ |
| Meta/Caption | Inter Medium 500 | 12–13px | `gray.500` | สถานที่, เวลา, จำนวนผู้เล่น |
| Button Label | Poppins Bold 700 | 15–16px | ตามพื้นปุ่ม | "เข้าร่วมแมตช์" |

## 4. ระบบระยะห่าง (Spacing / Grid)

ยึดระบบ 8pt grid ทั้งหมด: `4 / 8 / 12 / 16 / 24 / 32 / 40`

- Margin ซ้าย-ขวาของสกรีน: **24px**
- Padding ภายในการ์ด: **16px**
- ระยะห่างระหว่างการ์ดในลิสต์แนวตั้ง: **16px**
- ระยะห่างระหว่างการ์ดในลิสต์แนวนอน: **12px**
- ระยะห่างระหว่าง section ใหญ่ (Header → Filter → Matches): **24–32px**

## 5. โครงสร้างหน้าจอ (Screen Layout)

ลำดับจากบนลงล่าง (scroll เดียวทั้งหน้า ยกเว้น Header ที่ fix หรือ collapse เมื่อ scroll):

### 5.1 ส่วนหัว (Header)

- พื้นหลัง: gradient แนวตั้งจาก `green.500` (บน) ไป `green.900` (ล่าง) สูงประมาณ 200–220px
- มุมล่างซ้าย-ขวาโค้งมน **radius 28–32px** ให้ส่วนเนื้อหาด้านล่างดูเหมือน "ซ้อนทับ" ขึ้นมาเล็กน้อย
- แถวบนสุด: ซ้ายเป็นข้อความสองบรรทัด (บรรทัดเล็ก 70% opacity ขาว "ยินดีต้อนรับกลับมา" + บรรทัดใหญ่ตัวหนาขาว "ปอนด์ ศิริชัย 👋"), ขวาสุดเป็น avatar วงกลม 44–48px ขอบขาวบาง 1.5px พร้อมจุดแดงเล็กแจ้งเตือนถ้ามีการแจ้งเตือนใหม่
- แถวสถิติด่วน (ตัวเลือกเสริม): ชิปโปร่งแสงขาว 3 อัน วางแนวนอน เช่น "แมตช์ของฉัน 3", "คำขอใหม่ 2", "เพื่อน 12" — ให้ความรู้สึกมีชีวิตชีวาและกระตุ้นการมีส่วนร่วม

### 5.2 การ์ดค้นหาลอย (Floating Search Card)

- การ์ดสีขาว มุมโค้ง 24px วางซ้อนทับขอบล่างของ Header (ยกขึ้นด้วย negative margin ประมาณ -28px) พร้อมเงาชัดเจน (shadow y:8 blur:16 opacity:12%)
- ภายในมีช่องค้นหาทรงแคปซูล + ไอคอนแว่นขยายสีเทา
- แถวชิปกรองชนิดกีฬาแนวนอน เลื่อนได้: แต่ละชิปมีไอคอนกีฬา + ชื่อ (บาสเกตบอล, แบดมินตัน, ฟุตบอล, เทนนิส, วิ่ง, วอลเลย์บอล ฯลฯ) — ปกติ: พื้นขาว ขอบเขียวอ่อน ตัวอักษรเขียว / เมื่อเลือก: พื้นเขียวเข้มทึบ ตัวอักษรขาว

### 5.3 ส่วน "แมตช์ที่มีให้เข้าร่วม" (Matches Available)

แบ่งเป็นสองชั้นเพื่อความหลากหลายในการเรียกดู:

1. **แถวแนะนำ (แนวนอน):** หัวข้อ "แนะนำสำหรับคุณ" ตัวหนาสีเขียว + ลิงก์ "ดูทั้งหมด" ชิดขวา — การ์ดแบบ carousel กว้างการ์ดละ ~280px เลื่อนแนวนอน แสดง 3–4 แมตช์ที่ใกล้เวลาที่สุด/ตรงกีฬาที่ผู้ใช้สนใจที่สุด
2. **ลิสต์เต็ม (แนวตั้ง):** หัวข้อ "แมตช์ทั้งหมดวันนี้" ตามด้วยรายการการ์ดเรียงต่อกันแนวตั้งแบบละเอียด (spec การ์ดในหัวข้อ 5.4)

### 5.4 การ์ดแมตช์ (Match Card) — สเปกละเอียด

โครงสร้างจากบนลงล่างภายในการ์ดเดียว:

- **คอนเทนเนอร์:** พื้นขาว มุมโค้ง 20px เงานุ่ม (y:4–6, blur:12–16, opacity 8–10%) padding รอบใน 16px
- **แถวบน:** ซ้ายเป็นรูปสี่เหลี่ยมมุมโค้ง 14px ขนาด 56×56px — ถ้ามีรูปถ่ายจริงของกิจกรรม/สนาม ใช้รูปนั้น ถ้าไม่มีใช้ไอคอนกีฬา (บาส/แบด/ฟุตบอล ฯลฯ) สีเขียวบนพื้นเขียวอ่อน `green.100` แทน
  - มุมขวาบนของรูปนี้มี badge เล็กสีเขียวเข้มทึบ ตัวอักษรขาว ระบุชนิดกีฬา เช่น "บาสเกตบอล"
  - ขวาของรูป: ชื่อแมตช์ตัวหนา (เช่น "หาผู้เล่นบาสเกตบอล 3x3") และไอคอน bookmark เล็กมุมขวาบนสุดสำหรับบันทึกแมตช์ที่สนใจ
- **แถว meta (ไอคอน + ข้อความสีเทา 13px):**
  - 📍 สถานที่ — "สนามบาสในร่ม อาคารกีฬา 2"
  - 🕐 เวลา — "วันนี้ 18:00 น."
  - 👥 ผู้เล่น — แสดงเป็น avatar วงกลมซ้อนกัน (สูงสุด 3 คน + ป้าย "+N" ถ้าเกิน) ควบคู่กับแถบ progress บาง (พื้น `green.100`, แถบเติม `green.500`) และข้อความ "ต้องการอีก 2 คน (2/4)"
- **ปุ่ม CTA ล่างสุด:** ปุ่มแคปซูลเต็มความกว้างการ์ด (หรือชิดขวาถ้าจัดคู่กับปุ่มรอง) พื้นเหลือง `yellow.500` ตัวอักษรเขียวเข้ม/เกือบดำตัวหนา ข้อความ **"เข้าร่วมแมตช์"**
  - ถ้าผู้ใช้เข้าร่วมแล้ว: เปลี่ยนเป็นปุ่ม outline ขอบเขียว พื้นขาว ตัวอักษรเขียว ข้อความ **"ออกจากแมตช์"** เพื่อคงสถานะ "สีเหลือง = ยังไม่ได้ทำ, สีเขียว outline = ทำแล้ว/ย้อนกลับได้"

### 5.5 ปุ่มสร้างแมตช์ใหม่ (Floating Action Button)

- ปุ่มลอยวงกลม 56–60px มุมขวาล่างของจอ ระยะห่างขอบจอ 20–24px ลอยเหนือแถบเมนูล่าง
- พื้นหลัง **สีเขียวเข้ม** (ไม่ใช้เหลือง เพื่อคงกฎ "เหลือง = ลงมือทำกับแมตช์คนอื่น") ไอคอน "+" สีขาว พร้อมเงาสีเขียวจาง ๆ ให้มิติ (shadow สีเขียว opacity 25–30%)
- เมื่ออยู่บนสุดของหน้า (ยังไม่ scroll) ให้ขยายเป็น extended FAB ทรงแคปซูลแสดงข้อความคู่ไอคอน **"+ สร้างแมตช์ใหม่"** แล้วยุบเหลือวงกลมไอคอนอย่างเดียวเมื่อผู้ใช้เลื่อนจอลง (ประหยัดพื้นที่ระหว่างอ่านลิสต์)
- ตัวเลือกเสริม: แทรกการ์ดโปรโมทรูปแบบ banner ทุก ๆ 4–5 แมตช์ในลิสต์ พื้นเขียวอ่อน ข้อความ "อยากรวมเพื่อนเล่นกีฬาเอง?" พร้อมปุ่มเหลืองเล็ก "สร้างแมตช์ใหม่" เพื่อกระตุ้นให้ผู้ใช้เป็นเจ้าภาพเองด้วย ไม่ใช่แค่เข้าร่วม

### 5.6 แถบเมนูด้านล่าง (Bottom Navigation) — อ้างอิงเพื่อความสอดคล้อง

พื้นขาว เส้นแบ่งบางสีเทาอ่อนด้านบน 4–5 ไอคอน (หน้าหลัก / ค้นหา / แมตช์ของฉัน / โปรไฟล์) ไอคอน+label ที่ active เป็นสีเขียว ที่เหลือเป็นสีเทา

## 6. รายละเอียดสไตล์คอมโพเนนต์ (Component Styling Reference)

| องค์ประกอบ | มุมโค้ง (Radius) | เงา (Shadow) |
|---|---|---|
| ปุ่ม CTA / ชิป | 999 (แคปซูลเต็ม) | ปุ่มหลัก: y:4 blur:8 opacity 20–30% สีตามพื้นปุ่ม |
| การ์ดแมตช์ | 20px | y:4–6 blur:12–16 opacity 8–10% สีเทาเข้ม |
| การ์ดค้นหาลอย | 24px | y:8 blur:16 opacity 12% |
| รูปย่อ/ไอคอนกีฬาในการ์ด | 14px | ไม่มีเงา (flat) |
| FAB | วงกลมเต็ม (999) | y:6 blur:12 opacity 25–30% สีเขียว (colored shadow) |
| Header | มุมล่างเท่านั้น 28–32px | ไม่มีเงา (ใช้ gradient แทนความลึก) |

## 7. ปฏิสัมพันธ์และไมโครอินเตอร์แอกชัน (Interaction Notes)

- ปุ่มทุกปุ่ม/การ์ดที่กดได้ ต้องมี state ตอนกด (opacity ลดเหลือ ~0.8 หรือ scale ลงเหลือ 0.97) ให้รู้สึกว่า "ตอบสนอง"
- ระหว่างโหลดรายการแมตช์ ใช้ skeleton placeholder โทนเขียวอ่อนแทน spinner เปล่า ๆ เพื่อให้ดูลื่นไหลระดับโปรดักชัน
- Pull-to-refresh ใช้สปินเนอร์สีเขียว
- เมื่อกด "เข้าร่วมแมตช์" สำเร็จ ให้มี micro-feedback เช่น ปุ่มเปลี่ยนเป็นเครื่องหมายถูกชั่วขณะ + haptic vibration เบา ๆ เพื่อสร้างความรู้สึก "ชุมชนที่มีชีวิตชีวา" เหมาะกับกลุ่มนักศึกษา

## 8. เช็กลิสต์ทรัพยากรภาพที่ต้องเตรียม (Asset Checklist)

- ชุดไอคอนกีฬา (บาสเกตบอล, แบดมินตัน, ฟุตบอล, เทนนิส, วิ่ง, วอลเลย์บอล, ปิงปอง, ปั่นจักรยาน, โยคะ) ทั้งแบบ outline และ filled โทนสีเขียว
- รูปถ่าย/ภาพประกอบตัวอย่างต่อชนิดกีฬา (ถ้าต้องการใช้รูปจริงแทนไอคอนในการ์ด)
- ภาพ avatar เริ่มต้น (placeholder) สำหรับผู้ใช้ที่ยังไม่อัปโหลดรูป
- ภาพประกอบ empty state (เช่น ตัวการ์ตูนถือลูกบอล) สำหรับตอน "ยังไม่มีแมตช์ วันนี้ ลองสร้างเองดูไหม?"
- ไอคอนแอป/Splash screen ที่ใช้โทนเขียวมรกต + เหลืองทองให้ตรงกับแบรนด์
